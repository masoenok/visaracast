# VisaraCast — Releases

Öffentliche Release-Distribution der **VisaraCast** Android-TV / Fire-TV IPTV-App
(Quellcode privat). Die App prüft `update.json` beim Start und installiert neue
Versionen automatisch.

## Installation (Erstinstallation, sideload)
1. Neueste `visaracast-*.apk` aus [Releases](../../releases) laden.
2. Auf dem TV-Gerät installieren (Downloader-App / `adb install`).
3. Danach aktualisiert sich die App selbst.

## Web-Einstellungen
Nach dem Start im selben WLAN `http://<TV-IP>:8080` im Browser öffnen, um
Playlist-/EPG-URL bequem einzugeben.
